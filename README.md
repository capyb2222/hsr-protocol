# hsr-protocol 

- protos for an anime game with star and rail (last repo got deleted due to github stuff)

## Latest version: 4.6.51

- 4.6.51 means 4.7 beta so the proto will prob work for 4.7 as well (ofc they can add more protos in v2, v3, v4, etc)

## Note

- Older versions (4.2 and below): their clients resolve method pointers differently, and my dumper can't dump that accurately yet.
- If you need a specific older version, open an issue and I'll add it when I fix that.
